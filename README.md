# Михаил × Дарья — «Любовь как код от реальности»

Многостраничное свадебное приглашение в тёмной цифровой эстетике. Сайт
содержит отдельные маршруты для программы дня, дресс-кода и RSVP-анкеты.
Ответы гостей отправляются в прежнюю Google-таблицу через проверенный
обработчик Google Apps Script.

## Структура

- `/` — главный экран, приглашение и обратный отсчёт;
- `/details` — дата, программа и маршрут до Pine River;
- `/style` — дресс-код, палитра и просьба по цветам;
- `/rsvp` — пошаговая анкета гостя;

Детские фотографии не используются в интерфейсе. Файлы `misha.png` и
`dasha.png` оставлены в `public/` только как исходный архив и могут быть
удалены перед публикацией, если они больше не нужны.

## Локальный запуск

Нужен Node.js `22.13` или новее.

```bash
npm ci
npm run dev
```

После запуска сайт доступен по адресу, который выведет Vite.

## Проверка и сборка

```bash
npm run lint
npm run build:pages
```

Готовая статическая версия для GitHub Pages создаётся в папке `out`.

## Анкета

Анкета отправляется нативной HTML-формой в скрытый iframe. Благодаря этому
сайт не зависит от собственного API и работает как на серверном хостинге, так
и на GitHub Pages. Адрес обработчика указан в `components/RsvpForm.tsx`.

Чтобы проверить настоящую запись, заполните одну тестовую анкету и убедитесь,
что новая строка появилась в связанной Google-таблице. Автоматические тесты
не отправляют данные в таблицу.

## Публикация на GitHub Pages

1. Загрузите содержимое проекта в корень репозитория GitHub.
2. Откройте `Settings → Pages`.
3. В поле `Source` выберите `GitHub Actions`.
4. Запустите workflow вручную или отправьте новый commit в ветку `main`.

Workflow `.github/workflows/pages.yml` сам установит зависимости, соберёт
статическую версию и опубликует папку `out`. Он учитывает как репозиторий
`<логин>.github.io`, так и обычный проектный репозиторий с адресом вида
`<логин>.github.io/<репозиторий>/`.

## Основные команды

- `npm run dev` — локальная версия;
- `npm run lint` — проверка исходников;
- `npm run build:pages` — статическая сборка в `out` для GitHub Pages;
